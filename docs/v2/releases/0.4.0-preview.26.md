## SQL Server plan evidence names a seek on the primary key (#451)

When SQL Server answers a query through the table's primary-key index instead
of a declared index with the same key, `SqlServerNativePlanMapper` used to
report a plain `IndexSearch` on an index without a logical name, which no
consumer could tell apart from a foreign index. The catalog witness now reads
`is_primary_key`, and a seek on that index maps to `PrimaryKeySearch` with the
target and no index identity, the fact the SQLite and MongoDB mappers already
report for their key lookups. A scan of the primary-key index stays an
`IndexScan`.
