# Groundwork v2 0.4.0-preview.15

Unreleased. Version and package-consumer pins are advanced in the release-preparation
change after this implementation passes its provider gates; published previews
are not replaced by builds of this branch.

This preview aligns PostgreSQL persisted ordinal-identity ordering and keyset
continuation with the selected physical index pathkey.

## PostgreSQL ordinal-identity ordering

PostgreSQL query rendering now orders and advances continuations directly over
selected persisted ordinal-identity columns. It no longer wraps those
injective physical values in redundant `string_agg`/`unnest` ordinal-key
expressions, while ordinary logical string ordering retains its portable
UTF-16 ordinal rendering.

Relational rendering adds protected mapping-aware order and cursor hooks while
preserving the existing protected overloads for provider compatibility.

## Provider-owned batch projections

Native batched writes now derive persisted search and ordinal-identity values
from the provider's physical schema shape while retaining the caller's logical
unit for outcome correlation. Public unit-of-work writes therefore populate
provider-owned columns consistently with single-row writes.
Mixed-shape PostgreSQL and SQLite batches retain the original logical values
when falling back to per-row writes, avoiding a second derived-column projection.
