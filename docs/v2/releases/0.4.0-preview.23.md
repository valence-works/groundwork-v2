## Declared non-null columns order without a null rank (#441)

`QueryRenderOptions.NonNullColumns` names the columns the storage unit declares
as required; `StorageUnit.CreateQueryRenderOptions` fills it from the unit
declaration. The relational and MongoDB renderers accept that declaration, or
the selected index, as the non-null witness for an ordering term, so a query
that nominates no index keeps a plain ordering for a required column instead of
a null-rank term that changes the emitted command and can defeat the declared
index.
