# Groundwork v2 0.4.0-preview.6

This patch preview makes the Groundwork 2.0 documentation product verifiable
from the exact immutable package family. All 26 public packages and
`Groundwork.Tool` use version `0.4.0-preview.6` and are published only to the
Valence Works Groundwork Feedz source.

## Release identity and compatibility

The production source for this release is the merge of PR #380 to `main`,
commit `6bee65c383df828c45ce818aa2e5f285a816faaf`. The release-preparation
commit changes only release metadata, documentation, and install/version pins;
it does not change `src/`, `samples/`, or `benchmarks/`. Package repository
metadata on every artifact identifies the tagged release commit.

This release adds no public runtime API, diagnostic, provider behavior, or
persisted-schema change. Existing preview.5 catalogs remain compatible and no
schema apply or catalog recreation is required. Keep the complete 26-package
closure and the tool on one exact version; do not mix preview.5 and preview.6
packages in one process.

## Exact-package API documentation

Every packable public assembly now emits and ships its XML documentation next
to the assembly in the package. Analyzer, tool, and MSBuild-task packages use
an explicit pack target so their documentation is retained even though their
assemblies do not use the ordinary library output layout.

The release workflow generates a navigable API-reference index and one page
per shipped assembly from the exact package files. The generator binds package,
assembly, and XML hashes; compares the documented surface to the reviewed
net8.0 and net10.0 public-API snapshots; and fails if undocumented public
surface exceeds the checked-in baseline.

## Documentation product evidence

- Every public package README links to the stable Groundwork 2.0 portal.
- Executable snippets, internal links, external links, and generated package,
  provider, and capability matrices have drift gates.
- The public sample can run unchanged against SQLite, PostgreSQL, SQL Server,
  MongoDB, MySQL, and the deterministic in-memory reference provider. The
  dedicated evidence workflow refuses missing or skipped provider runs.
- The published-portal verifier checks exact version context, search guidance,
  responsive navigation, semantic code rendering, and visible edit/feedback
  links.
- The newcomer SQLite journey begins at the published exact-version portal,
  downloads the executable fixture at the exact source SHA into an empty
  directory, restores only from Feedz/nuget.org, and retains commands,
  provenance hashes, elapsed time, and declare/apply/write/query/aggregate
  outcomes.
- Portal policy checks refuse unreviewed Groundwork v1 runtime bridges,
  fallback aliases, compatibility shims, or dual-write guidance outside the
  explicit migration pages.

## Upgrade

Pin every Groundwork package and `Groundwork.Tool` to `0.4.0-preview.6` and
restore the complete closure from the Feedz source. No code, data, or schema
migration is required from preview.5.
