# Groundwork v2 0.4.0-preview.4

This patch preview fixes index-compatible relational ordering. All public
packages and `Groundwork.Tool` use the exact immutable version
`0.4.0-preview.4` and are published only to the Valence Works Groundwork Feedz
source.

This preview also adds the optional bounded affected-key evidence contract for
operation-identified retention (`RetentionAffectedKeyProjection`,
`RetentionOperationResult.AffectedKeys`, and
`IExactRetentionAffectedKeysStorageSession`). InMemory, SQLite, PostgreSQL, SQL
Server, and transaction-capable MongoDB enforce native `bound + 1` refusal,
canonical replay/conflict semantics, and atomic ledger/row mutation; standalone
MongoDB omits the capability.

## Release identity and compatibility

The production source for this release is the merge of PR #365 to `main`,
commit `512636524a343d30f15df5cf472cb0bbc36b9be9`. The release-preparation
commit changes only release metadata, documentation, and install/version pins;
it does not change `src/`, `samples/`, or `benchmarks/`. Package repository
metadata on every artifact identifies the tagged release commit.

All 26 package identities in `eng/public-packages.txt` remain one versioned
closure and must be upgraded together. This release preserves the public API,
diagnostic inventory, and persisted catalog contract from `0.4.0-preview.3`.
Existing `0.4.0-preview.3` catalogs remain compatible: no discard, migration,
or schema re-application is required.

## Index-compatible relational ordering

Relational renderers now use the selected provider-resolved index declaration
to omit a redundant null-rank expression only when that declaration proves the
ordered column is non-nullable. This lets matching composite indexes satisfy
the requested order without an unnecessary sort. Nullable or unproven columns
retain Groundwork's explicit portable null ordering.

PostgreSQL, SQL Server, MySQL, and SQLite retain their provider-specific
ordinal string, decimal, GUID, and keyset-continuation semantics. The public
renderer surface is unchanged. The correction is covered by renderer,
architecture, public-API, differential, and isolated live-provider gates.

## Upgrade

Pin every Groundwork package and the tool to `0.4.0-preview.4`, restore the
complete closure from the Feedz source, and deploy normally. Do not mix
`0.4.0-preview.3` and `0.4.0-preview.4` packages in one process.
