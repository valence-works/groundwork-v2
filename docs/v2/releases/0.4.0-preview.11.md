# Groundwork v2 0.4.0-preview.11

This preview corrects generated-sequence exact-append scaling on relational
providers.

## Relational exact append batches

SQLite, PostgreSQL, and SQL Server exact appends with a provider-generated
sequence now use bounded provider-native batches. Each batch carries an
explicit input ordinal through sequence allocation or the provider's generated
key output, so returned sequence values remain in input order even when the
provider returns rows in an unspecified order. The append ledger, replay and
conflict checks, rollback behavior, and durable high-water evidence are
unchanged; high-water state is updated once after the append's successful
chunks.

## Verbose PostgreSQL explain artifacts

Opt-in PostgreSQL explain assertions now retain `EXPLAIN (VERBOSE, FORMAT JSON)`
artifacts. The verbose output includes the exact plan expressions needed to bind
a SubPlan to its source column and UTF-16 ordinal transformation, while the
assertion continues to execute each existing parameterized
`RelationalQueryCommand` statement on the same connection and transaction. Index
selection, suppression behavior, and artifact names are unchanged.
