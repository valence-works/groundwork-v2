# Groundwork v2 0.4.0-preview.3

This patch preview fixes MongoDB portable JSON admission. All public packages
and `Groundwork.Tool` use the exact immutable version
`0.4.0-preview.3` and are published only to the Valence Works Groundwork Feedz
source.

## Release identity and compatibility

The production source for this release is the merge of PR #361 to `main`,
commit `0c55b1eba86b0296c453ea967a51b59a415c4a59`. The release-preparation
commit changes only release metadata, documentation and install/version pins;
it does not change `src/`, `samples/`, or `benchmarks/`. Package repository
metadata on every artifact identifies the tagged release commit.

All 26 package identities in `eng/public-packages.txt` remain one versioned
closure and must be upgraded together. This release preserves the public API,
diagnostic inventory, and persisted catalog contract from `0.4.0-preview.2`.
Existing `0.4.0-preview.2` catalogs remain compatible: no discard, migration,
or schema re-application is required.

## MongoDB portable JSON admission

MongoDB schema and runtime admission now accept every native BSON
representation produced by the portable JSON codec: objects, arrays, strings,
integers, doubles, decimals, booleans, and JSON literal `null`. A required JSON
column continues to reject a missing value or CLR `null`, while a JSON literal
`null` remains valid JSON content. The codec also refuses Mongo-only BSON values
recursively, including dates and object identifiers, before they can create a
write/admission disagreement. Schema application and runtime admission share
the same accepted-type vocabulary and retain precise type-drift diagnostics.

## Upgrade

Pin every Groundwork package and the tool to `0.4.0-preview.3`, restore the
complete closure from the Feedz source, and deploy normally. Do not mix
`0.4.0-preview.2` and `0.4.0-preview.3` packages in one process.
