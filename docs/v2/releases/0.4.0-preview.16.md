# Groundwork v2 0.4.0-preview.16

Unreleased development notes. These changes are not included in the published
`0.4.0-preview.15` packages.

## PostgreSQL required-key continuations

Shared relational keyset rendering now carries the selected index declaration's
nullability proof into continuation predicates. PostgreSQL's raw-string,
persisted ordinal-identity, GUID, and shared scalar paths omit logically
impossible null alternatives for proven required columns. Nullable columns and
null cursors retain their ordering semantics.

Provider-specific SQL Server and MySQL continuation overrides are unchanged.
Native-plan and release verification remain required before
publishing this preview.
