# Groundwork v2 0.4.0-preview.13

This preview restores PostgreSQL declared-index selection for bounded ordering on
non-null columns.

## PostgreSQL non-null ordering

PostgreSQL query rendering now emits the same explicit physical null placement
used by Groundwork index DDL when a selected index proves an order column is
non-null: ascending columns use `NULLS FIRST` and descending columns use
`NULLS LAST`. Because the column cannot contain nulls, this does not change the
portable result order. It does allow PostgreSQL's optimizer to match the query
pathkeys to the declared index instead of choosing a scan and sort solely due to
PostgreSQL's opposite implicit null-order defaults.

Nullable order columns retain their explicit portable null-rank expressions.
The same index-compatible rendering applies to scalar, string, and GUID order
keys.
