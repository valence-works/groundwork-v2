# Groundwork v2 0.4.0-preview.14

This preview aligns SQL Server ordinal string ordering with declared index
pathkeys and retains the PostgreSQL non-null ordering alignment from preview.13.

## SQL Server ordinal-identity ordering

SQL Server query rendering now orders and advances continuations over selected
persisted ordinal-identity columns directly. It no longer adds a redundant
`DATALENGTH` pathkey or cursor comparison for those injective physical values,
so marked indexes can satisfy the complete order. Raw logical string ordering
retains its `DATALENGTH` tie-break to preserve trailing-space ordinal semantics.

## Upgrade

After `0.4.0-preview.14` is published, pin every Groundwork package and
`Groundwork.Tool` to that exact version and restore the complete closure from
the Valence Works Groundwork Feedz source.
