## MongoDB execution evidence reports the server version

`ProviderExecutionEvidence.Provider` from the MongoDB provider now carries the
connected server's version (for example `7.0.24`) instead of the fixed schema
identity version `1.0`, matching the relational providers, which stamp
`DbConnection.ServerVersion`. A consumer that proves a capture came from the
server it probed can now do so for MongoDB (#433). The version is resolved once
per provider connection from `buildInfo` (the cluster description only carries a
wire-version approximation such as `7.0.0`), and is read on the first emission
rather than while a capture is being established.
