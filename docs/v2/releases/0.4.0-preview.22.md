## MongoDB inspection observation (#439)

`Inspect` reports one read command (`mongodb.inspect`) like every other MongoDB read;
it read the high-water document unobserved before.

## Rewritten search keys in typed evidence (#432)

- MongoDB bounded-query evidence no longer withholds the shape when the query
  orders by a persisted ordinal identity key: the term reports the source
  column with the `PhysicalSearchKey` transform and the `Ordinal` comparison,
  as the relational providers already did. Any other rewritten key still
  withholds the shape.
- The relational and MongoDB collectors no longer withhold every shape rendered
  against a unit that declares folded or element search keys for other
  columns; a query that emits such a provider-owned physical column fails
  closed as before.
- MongoDB plan sort keys over the renderer's computed `_groundwork_null_rank_N`
  and `_groundwork_ordinal_key_N` fields resolve to the source column with the
  `NullRank` or `OrdinalStringKey` transform from the computing `$set` stage; a
  computed field without its stage leaves the sort unobserved. Computed names
  are never exported as logical columns.
