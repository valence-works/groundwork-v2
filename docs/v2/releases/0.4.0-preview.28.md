# Groundwork v2 0.4.0-preview.28

Unpublished notes for the next preview; the reconcile pull request records the
canonical release run after publication.

## Keyset continuation pages carry their emitted predicate (#422)

A bounded query that continued from a keyset token used to withhold its whole
shape. `ProviderBoundedQueryEvidence.Continuation` now carries the value-free
continuation predicate every renderer emits: the lexicographic disjunction
(SQLite, SQL Server, MongoDB and PostgreSQL's fallback; each branch fixes the
order prefix and bounds the next term, recording whether the null alternative
was emitted beside the bound, with null tests and contradictions for null
cursors) or PostgreSQL's native row-value tuple. `ProviderPredicateOperator`
gains `IsNull`, `IsNotNull` and `None`, which bind no value, so
`ProviderPredicateFact.BindingId` is null for them. `HasContinuation` is true
exactly when the predicate is present, and a page whose predicate cannot be
represented still withholds the whole shape.

## Point reads carry a native plan and a catalog uniqueness witness (#423)

A point read's plan coverage was `Unsupported` and its uniqueness
`NotObserved` on every provider. Point reads now collect their native plan
through the same explain seam as bounded queries, and report uniqueness as
`Observed`, naming the enforced key columns and whether scope participates,
only when the provider catalog holds a valid, unfiltered unique index or
primary key over exactly the read's key columns (MongoDB's `_id` for the
addressed collection). Nothing is inferred from the declaration or from the
at-most-one materializer.
