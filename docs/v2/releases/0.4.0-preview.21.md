## Serialized-writer capability

`WellKnownCapabilities.SerializedWriter` (`groundwork.operational.serialized-writer`)
is advertised by a provider whose deployment admits one writing transaction at a
time; every other commit waits for the running one. SQLite advertises it; the
PostgreSQL, SQL Server, MongoDB and in-memory providers do not. A consumer that
batches background writes (for example a diagnostics drain) can keep each
transaction short where the capability is present and batch freely where it is
absent, instead of choosing one fixed batch size for every provider
(elsa-workflows/elsa-foundation#1598). `BatchWriteCapabilities.ForProvider` gains
a `serializedWriter` parameter and `SerializedWriterDescriptor`.
